## Dataset

### Download
The raw datasets used in experiments can be downloaded through the links in `get_dataset.sh`. 

If the dataset is downloaded from https://law.di.unimi.it/datasets.php, then you need to install [WebGraph](https://webgraph.di.unimi.it/) first, and run the following command to convert origin graph to ASCII edgelist.
```
java -cp "*" it.unimi.dsi.webgraph.ArcListASCIIGraph  $INPUT $OUTPUT
```

### Converting to CSR
In this paper, we convert all dataset into undirected graphs can delete the isoalted vertices. You can run the following command 
```
g++ -o EdgeListToCSR EdgeListToCSR.cpp
```
to compile. And the following command to convert graphs:
```
EdgeListToCSR $INPUT $OUTPUT #NUMBER_OF_LABELS
```
The input file should be ASCII edgelist. The output files include five files:
   - `$OUTPUT_xadj.bin`: the CSR vertex array
   - `$OUTPUT_edge.bin`: the corresponding edge list
   - `$OUTPUT_weight.bin`: the edge weight
   - `$OUTPUT_label.bin`: the edge label
   - `$OUTPUT.edgelist`: the processed ASCII edgelist

`#NUMBER_OF_LABELS` controls the range of **random edge labels** generated by `EdgeListToCSR`.
Each undirected edge gets one random integer label in `[0, NUMBER_OF_LABELS-1]`, written to
`$OUTPUT_label.bin` for both directions. This does **not** affect graph structure (`xadj/edge`),
only label values. Use any integer `>= 1` (for an unlabeled setup, use `1` so all labels are `0`).

Why random labels at all?
- They provide categorical edge types needed by the `metapath` walker.
- In `metapath`, the next hop is allowed only if the edge label matches the schema position.
- For `deepwalk`, `node2vec`, and `ppr`, labels are not used for transition weights.

So for datasets without real edge types, these random labels are a synthetic placeholder for
running metapath-style random walks; they are not required for other walk modes.

### Batch conversion example (for static datasets)
If your input files are in:

`/mnt/lustre/users/inf/ms2420/non-temporal-comparison-datasets/static`

and you want outputs in:

`/mnt/lustre/users/inf/ms2420/non-temporal-comparison-datasets/static_preprocessed_flowwalker/`

run:

```bash
cd data
g++ -O3 -std=c++17 -o EdgeListToCSR EdgeListToCSR.cpp

INPUT_DIR=/mnt/lustre/users/inf/ms2420/non-temporal-comparison-datasets/static
OUTPUT_DIR=/mnt/lustre/users/inf/ms2420/non-temporal-comparison-datasets/static_preprocessed_flowwalker
NUM_LABELS=32

mkdir -p "$OUTPUT_DIR"

for f in "$INPUT_DIR"/*.edgelist; do
  name=$(basename "$f" .edgelist)
  ./EdgeListToCSR "$f" "$OUTPUT_DIR/$name" "$NUM_LABELS"
done
```

This produces, for each input `${name}.edgelist`, the files:
- `${name}_xadj.bin`
- `${name}_edge.bin`
- `${name}_weight.bin`
- `${name}_label.bin`
- `${name}.edgelist`
